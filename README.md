# PlatePost 🍽️

A modern food-sharing social platform built with Flutter and Firebase where users can discover recipes, share food experiences, connect with other food enthusiasts, and build their own culinary community.

---

## 📱 Overview

PlatePost combines social networking with food discovery. Users can create profiles, publish recipe posts, interact through likes and comments, follow other users, and explore food content from the community.

The project was built to strengthen practical skills in Flutter, Firebase, state management, real-time data handling, authentication, and scalable mobile app architecture.

---

## ✨ Key Features

### Authentication

* Email & Password Sign Up
* Secure Login
* Password Reset
* Persistent User Sessions

### Social Features

* Create and Share Food Posts
* Like and Comment on Posts
* Reply to Comments
* Follow Other Users
* Personalized User Profiles

### User Profiles

* Edit Profile Information
* Update Profile Picture
* View Followers & Following
* Manage Personal Content

### Search & Discovery

* Search Users
* Discover New Food Content
* Explore Community Posts

### Real-Time Communication

* User-to-User Messaging
* Real-Time Chat Updates

### Personalization

* Dark Mode & Light Mode
* Custom User Settings

## 🚀 Getting Started

### Prerequisites

* Flutter SDK
* Android Studio or VS Code
* Firebase Project
* Android Emulator or Physical Device

### Installation

```bash
git clone <your-repository-url>
cd plate_post

flutter pub get

flutter run
```

---

## 🔥 Firebase Setup

1. Create a Firebase Project.
2. Enable Authentication.
3. Create a Firestore Database.
4. Configure Firebase Storage.
5. Run FlutterFire configuration.

```bash
flutterfire configure
```
